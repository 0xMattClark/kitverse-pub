## About KitVerse

[KitVerse.dev](https://kitverse.dev/) is a free toolbox for AI builders and developers. It brings AI workflow utilities and classic developer tools together in one place, without accounts, usage credits, or premium locks.

KitVerse is **local-first by design**: tool inputs are processed in your browser rather than uploaded to KitVerse servers. This makes it suitable for everyday tasks involving prompts, API responses, configuration files, and other content you would prefer to keep on your own device.

## Why KitVerse?

- **AI tools first** — Utilities built around real LLM and agent workflows, not just generic text tools.
- **Local-first processing** — Inputs stay in your browser and are never sent to KitVerse servers.
- **No signup or paywall** — Open a tool and start working. No account, credits, or locked premium tier.
- **Offline-friendly** — Local tools and exports remain available without a network connection after the relevant resources have loaded.
- **Transparent limitations** — Exact and estimated token counts are labeled, pricing data includes its source and date, and security findings are presented as review guidance rather than proof of safety.

## Featured AI Tools

### Skill Security Scanner

Audit agent skills and MCP configurations before giving them access to your tools, files, or credentials.

- Scan public GitHub repositories, directories, local files and folders, ZIP packages, or pasted text.
- Detect prompt injection, hidden or encoded instructions, dangerous commands, secret access, persistence, MCP tool poisoning, and suspicious dependencies.
- Review file-and-line evidence, risk scores, and OWASP Agentic / MITRE ATLAS mappings.
- Export individual or aggregate reports as JSON, Markdown, or SARIF 2.1.0.

[Open Skill Security Scanner](https://kitverse.dev/ai-tools/skill-security-scanner/)

### PUA AI Generator

Generate pressure prompts and complete skill files that encourage AI coding agents to exhaust every option before giving up. Choose a language and flavor, generate prompts locally, and turn a useful prompt into a reusable agent skill.

[Open PUA/PIP AI Generator](https://kitverse.dev/ai-tools/pip-ai-generator/)

### API Playground

Test REST and GraphQL APIs and debug WebSocket, SSE, Socket.IO, and MQTT connections directly from your browser. Inspect responses, timing, headers, and real-time events without installing a separate desktop client.

[Open API Playground](https://kitverse.dev/ai-tools/api-playground/)

> Browser-direct requests must follow web security rules. The target service needs suitable CORS headers; KitVerse does not proxy requests around those controls.

### More AI Workflow Tools

- **Tokenizer Playground** — Inspect tokenization and compare estimated costs across popular models.
- **RAG Chunking Playground** — Preview six chunking strategies with token counts, source offsets, and exportable results.
- **Prompt tools** — Compare prompt revisions, build structured prompts, expand variables in batches, and repair model-generated JSON.
- **Skill toolkit** — Validate, optimize, package, and convert reusable prompts into agent skills.
- **Model and provider references** — Compare pricing, context limits, and provider compatibility.
- **Daily New Words** — Keep up with new AI terms and concepts through a concise daily digest.

## Privacy at a Glance

| Area | How KitVerse handles it |
| --- | --- |
| Tool inputs | Processed locally in your browser |
| Accounts | Not required |
| Analytics of pasted content | Pasted inputs are not added to analytics events |
| Default saving | Inputs are not saved by default |
| Optional online checks | Clearly separated and initiated explicitly where applicable |
| Exports | Generated locally for you to download |

Remote resources, such as public repository URLs or optional vulnerability-intelligence checks, necessarily involve a request to the relevant external host. Refer to each tool's own notes for its exact behavior.

## Get Started

1. Visit [kitverse.dev](https://kitverse.dev/).
2. Search for a tool or browse the directory.
3. Enter your content and work locally in the browser.
4. Download or copy the result before leaving the page.

- Tools that are confusing or not working as expected
- False positives or missed risks in security scanning
